            Visualizer API (what to yield)
            

                
yield "compare", i, jHighlight two bars being compared

                
yield "swap", i, jYou swapped arr[i] and arr[j] (do the swap in your code too)

                
yield "set", i, vYou wrote arr[i] = v (merge sort, counting sort, shifts…)

                
yield "pivot", iMark a pivot / current minimum

                
yield "sorted", i[, j]Lock in a bar (or range i..j) as final

            

            
Name the function anything. The last public function taking exactly one argument (the list) is run. Plain functions that don't yield (e.g. arr.sort()) also work — the end result is animated. After playback the real result is verified, so a missing yield gets flagged.
