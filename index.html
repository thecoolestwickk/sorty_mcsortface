            how to write your own algorithm !!
            
    
                
  • The only public function should be the one that sorts the data. You must pass in arr (the array) to work. Put an _ at the start of a function to make the function private. If there are no/more than 1 private functions, it will not work.
    • 
                
  • The visualizer watches your list automatically. heres what each color means:
                    
      
                        
    • red: two items were compared (<, >, ==, min, max, sorted…)
      • 
                        
    • orange: two items traded places (arr[i], arr[j] = arr[j], arr[i])
      • 
                        
    • purple: a position was overwritten (arr[i] = x, arr.sort(), arr.reverse())
      • 
                        
    • green: a bar reached its final spot and never moves again
      • 
                    
    
                
    • 
                
  • In your function, it should edit arr in place. Do not return anything from your public function. If you return a new list from the function instead of editing in-place, it will not animate the result.
    • 
                
  • Custom algorithms are saved to your browser, so don't be scared of losing them!
